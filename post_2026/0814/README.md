#### ソースコードの説明

このディレクトリには、AIエージェントが標準テンプレートから新しいPythonプロジェクトの初期化を自動実行するためのスキル定義ファイル（`SKILL.md`）が配置されています。

- `SKILL.md`
  - **スキル名**: `python-project-initializer`
  - **目的**: テンプレートリポジトリから新規Pythonプロジェクトの構造と開発環境を初期化します。アプリケーションコードの実装は行わず、環境セットアップのみを安全かつ確実に実行することを目的としています。
  - **重要なルール**:
    - **ワークフロー順の遵守**: プロジェクトタイプ、プロジェクト名、説明文を決定してからテンプレートのクローンに進みます。
    - **初期化処理に特化**: コードの実装や編集は行わず、初期化完了後にユーザーへ報告して次の指示を待ちます。
  - **ワークフローステップ**:
    1. **プロジェクトタイプを決定**: 標準テンプレート（`python-base`）などの利用テンプレートを決定します。
    2. **プロジェクト名と説明を決定**: プロジェクト名および概要文を設定します。
    3. **テンプレートリポジトリをClone**: テンプレートリポジトリ（`python-project-template`）をクローンします。
    4. **Gitリポジトリを初期化**: 既存の `.git` を削除して `git init` を実行し、クローン元の履歴を引き継がずに新規リポジトリとして初期化します。
    5. **プロジェクト設定を更新**: `pyproject.toml` や `README.md` のプレースホルダー（`{{PROJECT_NAME}}`, `{{PROJECT_DESCRIPTION}}`）を置換します。
    6. **依存関係を同期**: `uv sync` を実行して仮想環境のセットアップとパッケージ依存関係の同期を行います。
    7. **初期コミットを作成**: 全ファイルをステージングして `Initial commit` を作成します。
    8. **完了を報告**: 初期化完了とプロジェクト情報（Pythonバージョン、依存関係など）を報告し、実装準備が整った状態にします。
